Notación

Los componentes son los elementos computacionales y almacenes de datos presentes en tiempo de ejecución; interactúan a través de puertos. Los conectores son las vías de interacción en tiempo de ejecución y exponen roles en sus extremos. Cada adjunción (attachment) asocia el puerto de un componente con el rol de un conector. La delegación de interfaz muestra cómo el puerto externo de Web SSR se conecta con su estructura interna.
